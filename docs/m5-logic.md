# Batch editing and export integration

Selection belongs to the active layer. A normal `selectKey` replaces the multi-selection; `selectKeys`, `toggleKey`, `selectRange` (inclusive position-index range anchored at the single selection), and `clearSelection` support board affordances. Switching layers clears the multi-selection. Clipboard offsets are position-index offsets from the smallest copied key; paste returns both written and skipped positions. The clipboard is internal and survives layer changes, but resets on load. Invalid positions or opaque bindings cause the entire edit to fail. `clearKeys` writes `&none` on the base layer and `&trans` on overlays, so overlays inherit lower-layer bindings.

The command registry exposes `edit.copy`, `edit.paste`, `edit.cut`, `edit.clear`, `edit.swap`, `edit.swap-layers`, `edit.assign-many`, and `layer.copy`. The UI supplies `CommandContext.batch` callbacks, including dialogs for operations needing extra inputs. Cut should copy first and then clear in one editing history entry. `batchShortcut` recognizes Cmd/Ctrl+C, V and X independently of the navigation scheme; invoke it only when the board owns focus so text fields and browser editing retain their normal shortcuts. No default shortcuts are assigned to operations requiring further choices.

`exportKeymap` returns standalone layer SVGs and printable HTML; `svgToPng` is a separate browser-only module that returns a PNG Blob. Render or download the returned data in the export dialog. Printed pages include a legend explanation and the model's custom behavior names and types.
